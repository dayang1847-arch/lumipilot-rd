# LumiPilot 电子方案助手：新版页面使用说明

2026-10-27。按已选择的第二张设计稿调整本地资料库界面。入口仍是本目录的 index.html；原工程检索界面保留为 index_v3.html。此次仅调整本地资料展示与沟通流程，未修改LumiPilot实际程序、原始研发资料或工程批准状态。

## 用一条逻辑看懂方案

1. **了解客户需要什么**：填写国家/地区、销售渠道、产品类型、主要目标；客户或项目名称可选。点击“查找可参考方案”。当前仅依据本批已有的四类历史场景召回线索，不使用外部AI，不自动判定客户规格。
2. **有哪些方案可参考**：并排查看历史路线和待补充的对照方向。按适用需求、设计特点、不适用情况、待确认事项和成本依据进行比较。“已有资料”表示有历史来源，不表示本次客户已批准；“待补资料”不表示已有可直接使用的候选。
3. **为什么这样选**：点击第三步，阅读历史设计理由、适用条件和成本口径。
4. **还要确认什么**：点击第四步或“整理客户待确认清单”，勾选沟通事项，填写问题或进展。勾选表示希望跟进，不表示测试通过或问题关闭。

## 切换阅读视角

- 客户视角：用更简明的文字说明需求与取舍，减少技术缩写。
- 销售视角：默认入口，保留适用条件、沟通重点和比较逻辑。
- 工程师视角：显示更具体的历史参数，并自动展开“参数、变更与验证”。

三种视角分别组织标题、对比项、选择理由和跟进清单：客户侧重使用需求与验收；销售侧重匹配、承诺边界和报价前置条件；工程师侧重电气边界、配置、验证和复用。事实来源和批准状态不随视角改变。视角不是账号权限。客户和销售可按需查看相应依据。

## 查历史案例与证据

“历史案例”列出MX/NOLA T8、ASEAN T8、EU/Cons GU10、Australia S13四类现有资料。选择案例后返回对应对比页。区域资料仍需明确具体国家；当前销售渠道和客户Benchmark需单独确认。国家匹配仅用于召回历史案例，不构成具体国家法规、客户适用或认证结论。

对比页的“展开工程参数与来源”可查看历史参数与原件链接。“技术资料”保留报告、方法说明、当前案例来源，以及可展开的完整知识网络、物料路径与版本核对；也可在新标签页打开原工程检索界面。

如果资料不能对应输入需求，页面会明确显示缺口，并提供浏览历史案例或整理待确认清单的入口，不生成虚构方案。

## 下载与保存

清单以UTF-8文本下载，包含当前需求、所选事项和补充说明。页面不会自动发送消息或写回资料库。也可使用浏览器“打印 / 保存为PDF”；此入口调用浏览器原生打印功能。

本次输入仅保留在当前页面，刷新会清除。需要留存时先下载清单。客户原始信息、BOM成本和来源文件不会自动上传到外部服务。

## 窄屏使用

导航切换到顶部。对比表在窄屏按“对比项标题 + 两类方案并排”的形式排列，不要求整页左右滚动。长内容可正常纵向查看；四步按钮和视角切换保留。

## 资料与边界

使用电子研发知识库v3及已核验本地只读快照。当前未补齐客户批准基准、生效配置、同条件候选和可比采购实价，页面不计算最优排名、批准替代或实际节省金额。详细资料整理方法仍见《系统工程方法与使用说明_v3.md》。
